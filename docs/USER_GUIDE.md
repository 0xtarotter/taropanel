# 使用教程

## 页面层级

```text
TaroPanel
├─ 服务总览
├─ 系统服务
├─ Docker 容器
│  ├─ 容器列表
│  └─ Compose 项目
├─ 防火墙
├─ 流量监控
├─ Web SSH
└─ 操作记录
```

顶部的“后台任务”显示 Compose 部署、软件安装等任务进度；“操作记录”展示当前登录页面中的服务操作，两者不是同一种持久审计日志。

## 总览与系统服务

总览展示服务数量、运行状态、主机内存和最近 24 小时的网卡流量。可以按名称、镜像或端口搜索，也可以筛选运行状态。

“刷新状态”手动获取新数据；自动刷新间隔可以调整，后台标签页会暂停自动刷新。停止或重启服务前应确认用途。面板自身的停止按钮受保护，需要通过外部 SSH 管理。

系统服务默认发现 `/etc/systemd/system` 下的普通 `.service` 文件，不代表系统所有服务。端口扫描的发现范围比此列表更广，因此防火墙页面出现额外服务名称属于正常情况。

## 创建独立 Docker 容器

1. 打开 **Docker 容器 → 容器列表**，点击“新建容器”。
2. 填写容器名称、镜像和重启策略。
3. 按需填写端口映射、环境变量和数据挂载，每行一项。
4. 创建完成后，在容器卡片点击“启动”。

例如，端口映射 `8080:80` 表示宿主机 8080 转发到容器 80。只供本机代理使用时可写 `127.0.0.1:8080:80`。

现有容器的在线编辑支持名称和重启策略；镜像、端口、挂载的变更需要重建容器。由 Compose 管理的容器应优先修改 Compose 文件，避免下次部署覆盖手工变更。

## 新建并部署 Compose 项目

打开 **Docker 容器 → Compose 项目 → 新建 Compose 项目**。

项目名使用小写字母、数字、短横线或下划线，并以字母或数字开头。下面是一个仅供功能体验的 Web 服务示例；先确认 8080 未被占用：

```yaml
services:
  web:
    image: nginx:alpine
    restart: unless-stopped
    ports:
      - "8080:80"
```

- **仅创建项目**：校验并保存配置，容器尚未启动。
- **创建并部署**：校验、保存，并提交后台部署任务。

部署时会执行 `docker compose up -d`。在“后台任务”中查看拉取镜像和启动结果，再到容器列表检查状态。

编辑已有项目时，依次使用“校验配置”“备份并保存”“部署已保存配置”。保存不会自动部署。已有项目支持多份 Compose 文件；校验按整个项目文件组合进行。

新项目的相对挂载路径以其项目目录为准。若需使用已有证书、配置文件，请先准备文件，并使用适当的主机绝对路径。页面不会替你创建 `.env` 中引用的秘密，也不会自动导入外部 Dockerfile 或构建上下文。

## 防火墙和端口扫描

页面显示的默认策略是 **默认放行**，表示本面板没有屏蔽未设置规则的端口，不代表外网一定可达。

| 状态 | 含义 |
| --- | --- |
| 默认放行 | 本面板未设置匹配的屏蔽规则 |
| 已记录放行 | 已显式保存放行记录及关联服务备注 |
| 已屏蔽 / 已配置屏蔽 | 存在本面板的屏蔽规则；还需看规则引擎是否已加载 |
| 仅本机 | 监听地址是回环地址，不能靠“放行”变成对外监听 |

点击“扫描已启用端口”后，可查看 TCP/UDP 监听及运行中 Docker 的宿主机映射。按端口号、服务名或容器名筛选，勾选后点击“一键放行所选端口”。

默认放行的端口只会新增记录；已屏蔽的端口会解除所选端口的屏蔽。一个端口位于屏蔽范围内时，面板会拆分范围，保留其他端口的屏蔽。放行时重新检查监听状态，过期的扫描结果可能要求重新扫描。

系统会自动填写关联服务备注；无法识别时明确显示未识别。备注记录的是应用规则时的关联关系，服务变化后可重新扫描并更新备注。

删除放行记录后仍为默认放行；删除屏蔽规则后才会解除对应屏蔽。面板和 SSH 管理端口受到保护。其他防火墙、路由器和云安全组仍可影响实际访问。

## 流量监控

可选择最近 24 小时、7 天、30 天或启用以来累计，并分别查看网卡、Docker 容器或系统服务。

首次启用需要等待采样；历史不足时显示已有数据。无独立计数的对象用“—”表示，不能当成 0。主机、容器和服务之间有重复统计，不要相加。隧道与物理网卡也可能重复计数。

## Web SSH

1. 进入 **Web SSH**，确认页面显示的连接账户。
2. 再次输入面板密码，点击“连接终端”。
3. 像普通 SSH 一样执行交互式命令。
4. 完成后点击“断开”或退出登录。

终端连接的是本机独立 SSH 服务。操作权限取决于安装时选择的 Linux 用户；面板不会自动授予该用户 sudo 权限。手机可以使用 Ctrl+C、Tab、Esc、方向键快捷按钮。

离开 SSH 页面会断开连接，15 分钟无输入或连接达到 2 小时也会断开。长时间任务建议先使用 tmux/screen；普通前台任务可能随 SSH 断开而停止。终端里的输出不写入面板操作记录，也不要把含秘密的终端截图上传到 Issue。
